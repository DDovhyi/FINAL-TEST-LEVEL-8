1.3. Sentence Construction & Pattern Selection (3 pts each — 18 pts)

Available Course Patterns:
  • Ought to: ought (not) to + V1 / be + V-ing / have + V3
  • Complex Object: verb + object + (to) V1 / V-ing (e.g., want/expect/allow sb to do, make/let sb do, see/hear sb doing/do)
  • Modal Expressions with "be": be about to / allowed to / bound to / due to / likely to / supposed to
  • Inversion: Seldom / Never / Little / Not only... or Hardly / Barely... when, No sooner... than
  • Emphasis: It is/was ... that/who/which or What ... is/was ...
  • Mixed Conditionals: If + Past Perfect, would + V1 (3rd/2nd) or If + Past Simple, would have + V3 (2nd/3rd)
